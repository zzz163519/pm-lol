#### Welcome on the GRID

GRID provides competitive gaming data through APIs. The data is split up in:

*   Static data: schedules, tournaments, teams, ...
*   In-game data: gameplay data, updated as a series is played

The documentation is here to:

*   Help you interact with our APIs as quickly as possible 
    *   Go to our [Static Data Quick-Start Guide](https://docs.grid.gg/documentation/api-documentation/static-data/data-feed-quick-start-guide)
    *   Go to our [In-Game Data Quick-Start Guide](https://docs.grid.gg/documentation/api-documentation/in-game-data/live-data-feed-quick-start-guide)

*   Explain how our APIs are designed
*   Provide you with a complete view of what is available 
    *   Go to our [API Reference](https://docs.grid.gg/documentation/api-reference/getting-started/overview)

#### Access

An authorised API key is required to gain access to each GraphQL API by setting the _x-api-key_ header on each _POST_ request. If you do not have an API key, or have any other questions around access, please contact our [Support Team](mailto:support@grid.gg).

#### Discover

To interact and discover what is available via GRID APIs, the following development tools are maintained.

##### GraphQL Playground

[GraphQL](https://graphql.org/) is a language that enables a flexible approach to querying APIs, by enabling the client to query only what is required. Most APIs offered as part of the GRID data feeds are queryable with GraphQL.

In order to discover and test different GraphQL queries across these APIs, the [_GraphQL Playground_](https://portal.grid.gg/documentation/graphql-playground) is available that allows live queries for real data. It is possible to view the schema for each API using the panel located on the right-hand side of the playground application.

##### Data Feed Viewer

The [Data Feed Viewer](https://dashboard.grid.gg/developers/feed-viewer) enables consumers to discover the events data contained within transactions, published by the [Series Events API](https://docs.grid.gg/documentation/api-reference/live-data-feed/series-events-api).
